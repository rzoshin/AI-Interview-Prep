## ✨ Features

### 📚 Question Explorer

* Browse interview questions by topic
* Search and filter questions
* Difficulty-based categorization
* Bookmark important questions

### 🤖 AI Answer Engine

Every question includes:

* Bangla ELI5 Explanation
* English ELI5 Explanation
* Beginner Answer
* Interview Answer
* Senior Developer Answer
* Code Examples
* Common Mistakes
* Follow-up Questions
* Related Concepts
* Quiz Questions

### 🎯 AI Mock Interview

* Interactive interview sessions
* AI-generated follow-up questions
* Instant answer evaluation
* Readiness scoring
* Personalized feedback

### 📖 Flashcards

* Topic-based flashcard decks
* Interactive card flipping
* Quick revision workflow
* Spaced repetition friendly

### 📊 Progress Tracking

Track:

* Readiness Score
* Topic Mastery
* Study Streak
* Questions Completed
* Focus Areas
* Strong Areas

### 🛣️ Smart Roadmap

AI-generated learning path based on:

* Current mastery
* Weak topics
* Quiz performance
* Interview results

### 🕸️ Knowledge Graph

Visual learning map connecting:

* HTML
* CSS
* JavaScript
* TypeScript
* React
* Next.js
* Node.js
* MongoDB
* System Design
* Data Structures

### 📄 PDF Question Extraction

Admins can:

* Upload interview question PDFs
* Automatically extract questions
* Categorize topics
* Generate AI explanations
